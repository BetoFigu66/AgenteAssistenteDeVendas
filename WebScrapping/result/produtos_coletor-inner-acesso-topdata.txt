Perguntas Frequentes
O que é o Inner Acesso? Ele é uma catraca completa?
Não. O Inner Acesso é um Coletor de Dados (ou terminal) para controle de acesso. Ele é o "cérebro" do sistema: um dispositivo que é instalado em uma parede ou totem para identificar o usuário. Após a autenticação, ele envia um comando para liberar o acesso a portas, portões, cancelas ou catracas, mas não é a barreira física em si.
Quais são os métodos de identificação que o Inner Acesso utiliza?
O Inner Acesso é um equipamento flexível e pode ser configurado com diferentes tipos de leitores, permitindo a identificação de usuários por:Biometria: Leitura da impressão digital (com capacidade para 10.000 digitais).Cartões de Proximidade (RFID): Compatível com as tecnologias 125k e Mifare.Código de Barras: Leitura de crachás com código de barras.Senha: Digitação de um código numérico diretamente no teclado do equipamento.
Quantos usuários e registros o equipamento consegue armazenar?
O dispositivo possui uma alta capacidade de armazenamento local. Ele pode gerenciar o cadastro de até 15.000 usuários (via cartão ou senha) ou até 10.000 impressões digitais. Além disso, ele armazena em sua memória interna os últimos 30.000 registros de acesso (entradas e saídas).
O equipamento para de funcionar se a rede ou o computador principal caírem?
Não. O Inner Acesso foi projetado para funcionar "com ou sem conexão com o computador". Ele armazena localmente a lista de usuários autorizados e suas permissões. Caso a rede ou o servidor fiquem offline, ele continua operando normalmente, autenticando usuários e registrando os acessos. Quando a conexão é restabelecida, ele sincroniza automaticamente os dados com o software.
Como o Inner Acesso se conecta ao software de controle de acesso?
A conexão padrão do Inner Acesso é via TCP/IP (cabo de rede RJ45), o que permite a comunicação com o software de gerenciamento (como o Secullum Acesso, mencionado na página) através da rede da sua empresa. A página do produto também indica a possibilidade de conexão via Wi-Fi ou 3G/4G com o uso de acessórios opcionais.
