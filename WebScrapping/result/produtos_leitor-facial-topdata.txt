A identificação facial é extremamente rápida e conveniente. Os usuários simplesmente precisam posicionar-se em frente ao leitor, sem a necessidade de inserir cartões ou digitar senhas. Perguntas Frequentes
Onde este leitor pode ser instalado? Ele é uma catraca completa?
Não, este produto é o leitor biométrico facial. Ele foi projetado para ser a "inteligência" do controle de acesso e pode ser instalado em diversas superfícies, como paredes (para liberar portas), totens, ou integrado diretamente em equipamentos como catracas, torniquetes e cancelas de estacionamento para comandar a liberação.
O leitor facial funciona no escuro ou em ambientes com pouca luz?
Sim. O dispositivo é equipado com iluminação automática por LED (luz branca e/ou infravermelha) que compensa a falta de luz ambiente. Isso garante que o reconhecimento facial seja rápido e preciso mesmo em locais totalmente escuros ou com baixa luminosidade.
É possível burlar o sistema usando uma foto ou vídeo do rosto de uma pessoa?
Não. O leitor possui a tecnologia de detecção de rosto vivo (liveness detection). Ele analisa profundidade e micro-movimentos para diferenciar um rosto humano real de uma imagem 2D (foto, vídeo) ou até mesmo de uma máscara 3D, impedindo tentativas de fraude e garantindo alta segurança.
O reconhecimento funciona se o usuário estiver usando máscara de proteção?
Sim. Os algoritmos do leitor são avançados e conseguem identificar a pessoa com precisão, mesmo que ela esteja usando uma máscara de proteção facial. O sistema foca nas características únicas da região dos olhos e testa para realizar a autenticação.
Como este leitor se integra ao meu software de gestão (academia, empresa, condomínio)?
O leitor é flexível e se comunica com a rede via TCP/IP. A Topdata fornece um SDK (Kit de Desenvolvimento de Software) que permite aos desenvolvedores integrar o leitor aos seus próprios sistemas de gestão (ERP, software de academia, portaria, etc.) para realizar o cadastro de faces e gerenciar as permissões de acesso. Ele também é compatível com os softwares de controle de acesso da própria Topdata.
